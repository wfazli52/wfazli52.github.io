# 90-Day Data Center Technician Portfolio Roadmap

This plan assumes roughly 8–12 focused hours per week. Reduce the weekly scope when school or work is heavy, but keep producing one visible deliverable at a time.

## Days 1–30: Foundation and first proof

### Week 1 — Set up the system

- Create a GitHub account and one public portfolio repository.
- Personalize `config.js`, `index.html`, and `resume.html`.
- Install Cisco Packet Tracer and a virtualization platform you can use legally on your computer.
- Create folders for diagrams, configs, evidence, tests, incidents, and reflections.
- Review PC/server components, copper and fiber basics, IPv4 addressing, common ports, DNS, DHCP, and the OSI/TCP-IP troubleshooting model.
- Deliverable: the portfolio is online with all projects clearly marked **planned**.

### Week 2 — Design Project 01

- Write the enterprise network requirements.
- Create four VLANs and an IP subnet plan.
- Draw the logical and physical topology.
- Define one access-control policy and at least eight acceptance tests.
- Deliverable: topology, IP plan, and blank test matrix committed to GitHub.

### Week 3 — Configure Project 01

- Configure device names, secure basic management, VLANs, access ports, trunks, gateways, and routing.
- Configure DHCP and DNS.
- Back up configurations before applying ACLs.
- Deliverable: working base network and sanitized configuration files.

### Week 4 — Break, fix, document

- Add the ACL and validate permitted/denied traffic.
- Create three faults: wrong VLAN, wrong gateway, and shutdown interface.
- Diagnose each fault using a written flow.
- Publish the final test matrix, troubleshooting notes, screenshots, and reflection.
- Update the website status to **completed** only when the evidence is public.

## Days 31–60: Systems operations and incidents

### Week 5 — Linux build

- Plan two VMs and document CPU, memory, storage, networking, naming, and purpose.
- Install Linux, patch it, create an admin user, configure SSH keys, time sync, and a host firewall.
- Deliverable: architecture diagram and secure-build checklist.

### Week 6 — Services and health checks

- Install a simple service such as Nginx.
- Learn `systemctl`, `journalctl`, `ss`, `ip`, `df`, `du`, `free`, `top`, `lsblk`, and basic log locations.
- Create a health-check script or written checklist.
- Deliverable: service runbook and normal-state evidence.

### Week 7 — Monitoring and recovery

- Add lightweight monitoring or centralized logs.
- Test reboot persistence.
- Back up and restore one configuration file.
- Create controlled failures: stopped service, low disk space, firewall block, and DNS error.
- Deliverable: recovery evidence and updated runbook.

### Week 8 — Incident simulation

- Create a ten-fault catalog using your network and Linux labs.
- Run three timed incidents without looking at the selected fault.
- Complete tickets, one full RCA, and one prevention runbook.
- Deliverable: Project 02 and Project 03 published.

## Days 61–90: Operations package, interviewing, and applications

### Week 9 — Rack and asset planning

- Create a rack elevation, device naming standard, asset inventory, port map, cable labels, and power assumptions.
- Write installation, validation, and rollback steps.
- Deliverable: draft operations package.

### Week 10 — Replacement and decommission scenarios

- Simulate a failed server or switch replacement.
- Update the asset record and cable map.
- Write a secure decommission checklist.
- Deliverable: Project 04 published.

### Week 11 — Resume and interview preparation

- Remove all resume placeholders.
- Write 6–8 STAR stories covering troubleshooting, learning, safety, conflict, customer service, prioritization, and a mistake.
- Practice explaining every project without reading notes.
- Practice common technical questions: boot process, RAID basics, storage types, DNS versus DHCP, VLANs, routing, ping/traceroute, Linux logs, ESD, cable types, and escalation.
- Deliverable: one-page resume and a 60-second introduction.

### Week 12 — Application system

- Apply to data center technician, deployment technician, hardware technician, network support, NOC, field technician, and IT operations roles.
- Tailor the top third of the resume to each job description without changing facts.
- Track applications, follow-ups, interview questions, and gaps discovered.
- Continue one lab improvement each week while applying.
- Deliverable: a consistent application pipeline and weekly review routine.

## Certification priority

Follow the certifications embedded in your WGU Cisco-track degree first. For the target role, emphasize practical CCNA-level networking, Linux fundamentals, server hardware, troubleshooting, and documentation. Avoid collecting unrelated credentials while projects remain unfinished.

## Weekly scorecard

- 1 publishable deliverable
- 1 troubleshooting exercise
- 1 technical explanation recorded aloud
- 5–10 targeted applications after the first completed project
- 1 improvement to the resume or portfolio based on feedback
