90-day roadmap

Build, document, apply.

A small completed portfolio beats ten unfinished ideas. Aim for one publishable deliverable every two weeks and begin applying before everything is perfect.

Days 1–30

Foundations + Project 01

Set up GitHub, Packet Tracer, your documentation folders, and complete the enterprise network lab. Practice subnetting, cable types, core hardware, DNS, DHCP, and the OSI/TCP-IP troubleshooting flow.

Days 31–60

Linux operations + incident evidence

Build the Linux lab, capture clean logs and screenshots, then run at least five break/fix scenarios. Publish one full incident report and one short runbook.

Days 61–90

Rack plan + applications

Finish the operations project, update the resume, practice behavioral and technical interviews, and apply weekly to data center technician, deployment technician, network support, NOC, and field technician roles.
