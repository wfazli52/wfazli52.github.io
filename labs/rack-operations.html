Rack, Cabling & Asset Operations

A physical-operations style lab for rack elevations, cabling, A/B power, asset control and shift handoff.

This is a build plan, not a claim that the lab is complete. Status changes only after Abdul runs the work and publishes his own sanitized evidence.

Build goals

  • Create a rack elevation
  • Map network and power paths
  • Build an asset register and labeling standard
  • Simulate a component swap and shift handoff

Evidence checklist

  • Rack elevation
  • Cable/port map
  • Asset register
  • Power map
  • Replacement checklist
  • Handoff note

Upstream tools / references

  • NetBox

Upstream source remains credited to its original maintainers. Abdul's portfolio will document only his lab configuration, testing, troubleshooting, and conclusions.
