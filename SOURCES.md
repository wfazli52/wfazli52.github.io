# Public reference points used to shape this starter

- Google data center technician postings emphasize troubleshooting operating systems, computer/server hardware, networking protocols, component-level repairs, and data center or NOC experience.
- AWS data center technician/network technician postings emphasize hardware troubleshooting and repair, networking, TCP/IP/DNS, rack installation, break/fix, incident response, documentation, and physical equipment handling.
- Microsoft describes data center technician work as preparing, installing, diagnosing, troubleshooting, replacing, and decommissioning equipment while following standard processes and data-management procedures.
- Microsoft Learn provides a vendor-neutral Introduction to Datacenter learning path.
- Cisco Networking Academy provides Packet Tracer as a virtual networking lab.

Verify current job requirements on each employer's official careers site before applying; postings vary by location and level.
